# Project design skills

Use the shared skills in `.agents/skills` for relevant design and prototype work in this project. Read the matching `SKILL.md` before starting:

- **Outlook UI, add-in panes, and email/calendar flows:** `.agents/skills/outlook-design/SKILL.md`.
- **Dynamics 365 Sales and Customer Service UI and flows:** `.agents/skills/dynamics-365-design/SKILL.md`.

For work spanning both products, apply each skill to its corresponding surface. Follow each skill's scope and read its bundled references when needed. These skills provide design guidance; they do not connect to live Microsoft services.

Keep complete skill folders, including `agents` and `references`, in the shared project. Team setup and example prompts are in `TEAM-SKILLS.md`.

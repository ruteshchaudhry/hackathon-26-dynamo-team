# Hackathon 26 Dynamo Team

Shared project workspace and Codex design skills for the hackathon team.

## Get started

```sh
git clone https://github.com/ruteshchaudhry/hackathon-26-dynamo-team.git
cd hackathon-26-dynamo-team
```

Open this folder as your project in Codex. The shared skills live in `.agents/skills`:

- **Outlook Design** (`$outlook-design`): Outlook interface components, add-in panes, and email/calendar prototypes.
- **Dynamics 365 Design** (`$dynamics-365-design`): Sales and Customer Service screens and prototypes.

Project instructions in [AGENTS.md](AGENTS.md) direct Codex to use the relevant skill. See [TEAM-SKILLS.md](TEAM-SKILLS.md) for setup, example prompts, and updates.
